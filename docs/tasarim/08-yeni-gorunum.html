"Akış" görünümü — öneri

Voyar destek ekranının havasından esinlenildi; renkler Nokta logosunun mavisinden (#0093DD) türetildi

Mürekkep (ink)#0B2A45 / #E6EEF6
Nokta mavisi (brand)#0093DD / #3DB4F2
Açık mavi zemin#E6F4FC / #0F2E44
Sayfa zemini#EEF3F7 / #08131F
Kart#FFFFFF / #0F1D2C
Çizgi#D6E1EA / #22384D
Başarı#0F8A52 / #4FD08F
Tehlike#C0322B / #F2837C

Ne değişir

  • Yazı tipi: sistem fontu yerine Geologica (açık lisans, sunucudan servis edilir)
  • Köşeler: kart 16px, sohbet balonu 24px (konuşana bakan köşe 6px), butonlar tamamen yuvarlak
  • Gölge yerine ince çizgi; sayfa zemini açık mavi-gri, kartlar beyaz
  • Sohbet: kendi mesajın sağda koyu lacivert, karşı taraf solda beyaz kart
  • Menüde seçili öğe açık mavi zemin + mavi ikon; sayaçlar yuvarlak rozet

Ne değişmez

  • Ekran düzenleri, akışlar ve metinler (yalnız görsel dil değişir)
  • Konsol sahnesi, işaretleme renkleri ve kırmızı "uzaktan kontrol" çerçevesi
  • Açık / Koyu / Sistem tema tercihi; koyu temada logo açık kart içinde
  • Erişilebilirlik: metin kontrastı WCAG AA, hareket azaltma desteği
  • Token'ların tek kaynağı globals.css — bileşenler değişmez, renk/yarıçap değerleri değişir
